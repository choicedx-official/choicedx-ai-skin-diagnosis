Legacy marketing/guidebook HTML should be reviewed using `Docs/migration/legacy-pages-canonical-policy.md` and migrated to `noindex,follow` with canonical links to existing official ChoiceDx pages when substantially duplicated.

## Assets

Existing `outputs/assets/` files should not be deleted solely as part of this renewal because legacy backlinks or pages may still reference them.
