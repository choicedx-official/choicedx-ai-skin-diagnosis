# ChoiceDx Terminology Policy

Last verified: 2026-08-11

## Primary principle

Use **Analysis** as the canonical product, technology and navigation term. Keep **Diagnosis** only as a secondary search synonym when it matches common user wording.

| skin analyzer | skin diagnostic device |
| AI scalp analysis | AI scalp diagnosis |

## Usage rule

Canonical terms should appear in:
- repository descriptions;
- page titles;
- H1 headings;
- entity definitions;
- structured data;
- primary internal anchors.

Secondary terms may appear in:
- FAQ questions;
- keyword maps;
- natural explanatory text;
- historical/legacy migration notes.

## Medical caution

Do not imply that the secondary word “diagnosis” automatically means a medical diagnosis. Repository content concerns beauty analysis and consultation support unless a specific regulatory/product source states otherwise.
