## Operational rules

1. One query family should have one primary official destination.
2. Supporting GitHub documents should link to that destination instead of competing with it.
3. Use secondary diagnosis terms naturally in FAQs and synonym maps, not as the primary title for every page.
4. Do not repeat identical anchor text or image ALT mechanically.
5. Review Google, Naver and Bing query-to-URL data before changing the routing map.
6. Search synonyms do not change the medical positioning: ChoiceDx repository content describes non-medical beauty analysis unless a specific regulatory source states otherwise.
