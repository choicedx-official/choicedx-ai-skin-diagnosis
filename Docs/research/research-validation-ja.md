# ChoiceDx AI肌分析 研究・検証

## 要約

ChoiceDx公式の研究・検証ページでは、**CTK Derma AI研究**をもとにAI肌分析の信頼性を考えるための検証要素を整理しています。

- 研究参加者：**265名**
- 肌タイプ：**Fitzpatrick I–VI**
- 反復撮影：**3回（3× repeated captures）**
- 検証フロー：**標準化された肌撮影 → Capture Calibration → AI定量分析 → 専門家評価との比較・再現性確認**
- 代表的な評価項目：**毛穴、色素性スポット、シワ、肌色**
- 原著論文：https://www.scirp.org/journal/paperinformation?paperid=153000

これらは特定の研究設計で得られた結果です。すべてのChoiceDx製品、構成、撮影条件、地域、分析項目に同一の精度を保証するものではありません。

## AI肌分析で確認すべきこと

AI肌分析の検証では、1回のスコアだけではなく、次の観点を組み合わせて確認することが重要です。

1. **多様な肌タイプ**が評価に含まれているか
2. 照明・カメラ条件が**標準化**されているか
3. 肌色や撮影環境による画像差を**補正**しているか
4. AI結果が**専門家の視覚評価**とどのような関係を示すか
5. 同条件で繰り返した際に結果がどの程度**安定・再現**されるか

## 研究フロー

### 1. 標準化された肌撮影

照明とカメラ条件を一定に管理し、入力画像のばらつきを抑えます。画像ベースのAI分析では入力品質が結果比較に大きく関わります。

### 2. Capture Calibration

肌色や撮影環境によって生じる画像差を補正します。ChoiceDx公式ページではこの工程を**Capture Calibration**として説明しています。

### 3. AI定量分析

定義された顔領域から画像特徴を定量化します。公式研究ページでは毛穴、スポット、シワ、肌色を代表的な評価対象として示しています。

### 4. 結果検証

AI分析結果を専門家の視覚評価と比較し、反復撮影によって結果の安定性を確認します。

## 多様な肌タイプ

研究にはFitzpatrick Phototype **I–VI**が含まれています。限られた肌タイプだけを対象とするよりも、幅広い肌色で分析結果を検討できる設計です。

ただし、I–VIを含むことと、あらゆる実環境で同一性能を保証することは同義ではありません。撮影品質、機器構成、ソフトウェアバージョン、分析項目などの条件を考慮する必要があります。

## 反復測定

公式ページでは**3× repeated captures**を検証要素として示しています。反復測定は、同じ状態を同条件で複数回撮影した際に、分析結果がどの程度安定するかを確認するための方法です。

店舗やプロフェッショナルカウンセリングで再来店比較を行う際は、照明、距離、姿勢などの撮影条件を可能な限り揃えることが重要です。

## 専門家評価との比較

ChoiceDx公式ページでは、**撮影補正を適用したCTK Derma AIが、補正なしのControlよりも、評価対象となった毛穴、スポット、シワ、肌色で専門家評価とのより強い相関を示した**と研究結果を要約しています。

これは**当該研究に限定された比較結果**として扱う必要があり、ChoiceDxのすべての機能に対する一般的な臨床精度保証へ拡張してはいけません。
