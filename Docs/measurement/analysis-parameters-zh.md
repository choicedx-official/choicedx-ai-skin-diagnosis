# ChoiceDx 分析项目指南

ChoiceDx 基于高分辨率图像以及光学/测量数据分析皮肤、头皮与毛发状态。官方分析项目页面说明了广泛的分析概念，并提到在韩国累计超过100万次的测量运营经验。

## 皮肤分析概念

|---:|---|---|

| 2 | **油分** | `oiliness` |

| 15 | **弹性相关特征** | `elasticity` |

### Interpretation principle

每个项目应作为帮助理解当前状态并支持咨询的**信息信号**。不应仅凭单一指标判断整体皮肤状态，应结合拍摄条件与其他分析结果综合理解。

例如，毛孔、皮脂和油分可能互相关联，但并不是同一个概念；肤色、色素沉着和可见色斑也描述不同的视觉特征。

## 重要的范围说明

本列表是ChoiceDx整体内容使用的**分析概念库**，并不表示所有设备、应用、市场或软件授权都会同时提供全部项目。具体可用项目应以最新产品页面和实际配置为准。

水分、油分、弹性等概念在不同产品配置下可能采用不同的测量/分析方式。本文档不定义医疗检测方法，仅用于规范非医疗美容分析术语。
