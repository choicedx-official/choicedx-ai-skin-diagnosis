# ChoiceDx 分析項目ガイド

ChoiceDxは高解像度画像と光学・測定データを活用し、肌・頭皮・毛髪状態を分析します。公式の分析項目ページでは、韓国内で累計100万件以上の測定運用経験を背景に、幅広い分析コンセプトを説明しています。

## 肌分析コンセプト

| No. | Parameter | Machine key |
|---:|---|---|
| 1 | **水分** | `moisture` |
| 2 | **油分** | `oiliness` |
| 3 | **シワ** | `wrinkles` |
| 4 | **皮脂** | `sebum` |
| 5 | **毛穴** | `pores` |
| 6 | **角質** | `keratin` |
| 7 | **シミ・スポット** | `spots` |
| 8 | **色素沈着** | `pigmentation` |
| 9 | **クマ** | `dark_circles` |
| 10 | **ツヤ・輝き** | `radiance` |
| 11 | **赤み・敏感度** | `redness` |
| 12 | **肌色・肌トーン** | `skin_tone` |
| 13 | **肌キメ・質感** | `texture` |
| 14 | **色むら・着色** | `discoloration` |
| 15 | **弾力関連特性** | `elasticity` |

### Interpretation principle

各項目は、現在の状態を理解しカウンセリングを具体化するための**情報シグナル**として扱います。1項目だけで肌状態全体を断定せず、撮影条件や他の分析結果とあわせて考えることが重要です。

例えば、毛穴・皮脂・油分は関連する場合がありますが同一概念ではありません。肌色・色素沈着・シミもそれぞれ異なる可視的特性を示します。

## 重要な範囲上の注意

この一覧はChoiceDx全体のコンテンツで扱う**分析コンセプトのライブラリ**であり、すべての機器・アプリ・市場・ライセンスで全項目が同時に利用できることを意味しません。実際の対応項目は製品・ソフトウェア構成・市場によって異なるため、最新の製品ページを確認してください。

水分、油分、弾力などの項目は製品構成によって測定・分析方法が異なる場合があります。本資料は医療検査法を定義するものではなく、非医療のビューティー分析用語を整理するための資料です。
