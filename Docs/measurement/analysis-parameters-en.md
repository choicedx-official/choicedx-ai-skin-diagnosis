# ChoiceDx Analysis Parameters Guide

ChoiceDx analyzes skin, scalp and hair conditions using high-resolution images and optical/measurement data. The official Analysis Parameters page describes a broad parameter library and states more than one million cumulative measurement-operation experiences in Korea.

### Interpretation principle

Each parameter should be treated as an **information signal** that helps describe visible condition and structure a consultation. A single parameter should not be used to characterize the entire skin condition without context.

For example, pores, sebum and oiliness may be related but are not identical concepts. Skin tone, pigmentation and visible spots likewise describe different visual characteristics.

## Important scope note

This is a **concept library across ChoiceDx content**, not a promise that every device, app, market or license exposes every parameter at the same time. Configuration-specific availability should be checked on the current product page.

Terms such as moisture, oiliness and elasticity may also be implemented differently by product/configuration. This document does not define a medical test method; it normalizes non-medical beauty-analysis terminology.
