# ChoiceDx 분석 항목 가이드

ChoiceDx는 고해상도 피부 영상과 광학·측정 데이터를 바탕으로 피부·두피·모발 상태를 분석합니다. 공식 분석 항목 페이지는 국내 누적 100만 건 이상의 측정 운영 경험을 기반으로 다양한 분석 개념을 설명합니다.

### Interpretation principle

각 항목은 고객의 현재 상태를 이해하고 상담 질문을 구체화하는 **정보 신호**로 사용합니다. 하나의 항목만으로 피부 상태 전체를 단정하지 않으며, 촬영 조건과 다른 분석 결과를 함께 고려하는 것이 좋습니다.

예를 들어 모공, 피지, 유분은 서로 관련될 수 있지만 동일한 개념이 아닙니다. 피부톤, 색소침착, 기미·잡티 역시 각각 다른 시각적 특성을 설명합니다.

## 중요한 범위 주의

이 목록은 ChoiceDx 전체 콘텐츠에서 다루는 **분석 개념 라이브러리**입니다. 모든 기기·앱·국가·라이선스에서 모든 항목이 동시에 제공된다는 의미가 아닙니다. 실제 지원 항목은 제품, 소프트웨어 구성, 시장과 계약 조건에 따라 달라질 수 있으므로 제품별 공식 페이지를 확인해야 합니다.

또한 피부 수분·유분·탄력과 같은 표현은 제품별 측정 방식이 다를 수 있습니다. 본 문서는 의료 검사법을 정의하지 않으며, 비의료 뷰티 상담을 위한 개념 정리를 목적으로 합니다.
