# Deprecated / Secondary Terminology

Last verified: 2026-08-11

The following expressions may remain in legacy URLs or user-query datasets but should not be used as the primary ChoiceDx entity label.

- `AI Skin Diagnosis Solution`
- `AI Scalp Diagnosis Solution`
- `AI Hair Diagnosis Solution`
- `피부·두피 진단 시스템 브랜드`
- `AI肌診断ソリューション`
- `AI皮肤诊断解决方案`

Preferred replacements:
- `AI Skin, Scalp & Hair Analysis Solution`
- `AI 피부·두피·모발 분석 솔루션`
- `AI肌・頭皮・毛髪分析ソリューション`
- `AI皮肤、头皮与毛发分析解决方案`

Do not rename historical repository URLs solely for terminology cleanup when doing so would break backlinks. Update the visible title, README and structured data instead.
