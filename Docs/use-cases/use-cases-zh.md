# ChoiceDx 应用环境与案例指南

ChoiceDx将AI皮肤、头皮与毛发分析定位为更完整的顾客体验流程：**分析 → 理解 → 咨询 → 产品探索 → 顾客历史 → 复访比较**。

## 1. 健康美妆与零售门店

### 搜索意图
`零售皮肤分析`、`门店皮肤分析`、`Skin Scan`、`AI皮肤分析门店`、`皮肤分析产品推荐`

典型流程：
1. 顾客进行皮肤和/或头皮分析
2. 结果突出可见或测量项目
3. 顾问或自助界面解释结果
4. 将分析与相关产品信息连接
5. 记录可用于复访比较和顾客历史管理

官方应用案例：https://www.choicedx.com/zh/references

## 2. 药店 / K-Pharmacy

### 搜索意图
`药店皮肤分析`、`药店头皮分析`、`药店皮肤分析仪`

在药店零售环境中，可视化的皮肤/头皮分析信息可用于支持非医疗美容与个人护理咨询以及产品探索。

**注意：** 在药店使用并不意味着ChoiceDx美容分析结果自动成为医疗诊断。

## 3. 美发沙龙与头皮护理空间

### 搜索意图
`头皮分析仪`、`美发沙龙头皮分析`、`AI头皮分析`、`毛发分析仪`

通过放大观察和头皮/毛发分析，专业人员可与顾客共同查看头皮状态、毛发密度等可视信息，并将其用于护理沟通与产品信息说明。

## 4. 美容护理、SPA与专业咨询

### 搜索意图
`美容院皮肤分析仪`、`专业皮肤分析仪`、`SPA皮肤分析`

专业顾问可以与顾客一起查看图像和分析结果，用于讨论关注重点、家庭护理产品信息以及复访时的记录比较。

## 5. 诊所与专业渠道

ChoiceDx产品可出现在专业咨询环境中，但本资料仅说明**非医疗美容分析**，不定义医疗诊断或治疗范围。

## 6. 自助式 / 无人体验

### 搜索意图
`皮肤分析终端`、`自助皮肤分析`、`无人皮肤分析`、`美妆分析终端`

Dx-Self支持顾客独立进行皮肤、头皮和毛发分析，并查看结果与产品信息。

官方产品：https://www.choicedx.com/zh/product/dx-self

## 7. 品牌快闪与体验空间

Dx-Smart、Dx-Pico等便携设备可用于快闪店、品牌体验区及活动型咨询等对移动性和空间效率要求较高的环境。

## 8. 全球零售

多语言软件和品牌定制有助于构建本地化顾客体验。实际支持语言、UI范围、软件许可和市场可用性应按具体产品与项目确认。
