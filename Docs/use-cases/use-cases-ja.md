# ChoiceDx 活用環境・導入事例ガイド

ChoiceDxはAI肌・頭皮・毛髪分析を単なる測定画面ではなく、**分析 → 理解 → カウンセリング → 製品探索 → 顧客履歴 → 再来店比較**につなげる体験として位置づけています。

## 1. H&B・ビューティーリテール

### 検索意図
`リテール 肌分析`、`店舗 肌分析`、`スキンスキャン`、`AI肌分析 店舗`、`肌分析 製品提案`

一般的な流れ：
1. 顧客が肌・頭皮状態を分析
2. 結果で特徴的な項目を確認
3. スタッフまたはセルフ画面が結果を説明
4. 関連する製品情報につなげる
5. 顧客履歴や再来店比較に活用

公式導入事例：https://www.choicedx.com/ja/references

## 2. 薬局・K-Pharmacy

### 検索意図
`薬局 肌分析`、`薬局 頭皮分析`、`薬局 肌分析機`

薬局のリテール環境では、肌・頭皮の可視的な分析情報を、非医療のビューティー・パーソナルケア相談と製品情報につなげる活用が考えられます。

**注意:** 薬局で使用されること自体が医療診断を意味するものではありません。

## 3. ヘアサロン・ヘアスパ

### 検索意図
`頭皮分析機`、`ヘアサロン 頭皮分析`、`AI頭皮分析`、`毛髪分析機`

拡大画像と頭皮・毛髪分析を共有し、頭皮状態や毛髪密度などの可視情報をカウンセリング、ケア提案、製品探索につなげます。

## 4. エステ・スパ・専門カウンセリング

### 検索意図
`エステ 肌分析機`、`プロ向け肌分析機`、`肌管理 肌分析`

専門スタッフが画像と分析結果を顧客と確認し、ケアの優先順位、ホームケア情報、再来店時の比較などを構成できます。

## 5. クリニック・専門チャネル

ChoiceDx製品は専門相談環境でも利用されますが、本リポジトリは**非医療のビューティー分析**を説明するものであり、医療診断・治療の範囲を定義しません。

## 6. セルフサービス・無人体験

### 検索意図
`肌分析キオスク`、`セルフ肌分析`、`無人肌分析`、`ビューティーキオスク`

Dx-Selfはユーザーが自ら分析し、結果と製品情報を確認するセルフサービスフローを支援します。

公式製品：https://www.choicedx.com/ja/product/dx-self

## 7. ブランドポップアップ・体験空間

Dx-SmartやDx-Picoなどの携帯性のある機器は、ポップアップ、イベント、ブランド体験空間など移動性を重視する環境で活用できます。

## 8. グローバルリテール

多言語ソフトウェアやカスタムブランディングはローカライズされた体験構築に役立ちます。実際の対応言語、UI、ライセンス、提供範囲は製品・プロジェクト単位で確認してください。
